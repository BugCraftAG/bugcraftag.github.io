## Datenschutz

Diese Seite setzt keine Cookies und verwendet keine Analyse- oder Tracking-Werkzeuge. Schriften und Bilder liegen auf demselben Server wie die Seite.

Hosting: Die Seite wird über GitHub Pages (GitHub Inc., USA) ausgeliefert. Dabei verarbeitet GitHub technisch notwendige Zugriffsdaten wie die IP-Adresse.

Musik-Vorschau: Erst wenn Sie im Musik-Fenster auf „Abspielen“ klicken, werden eine 30-Sekunden-Hörprobe und das Cover von Servern von Apple (audio-ssl.itunes.apple.com, is1-ssl.mzstatic.com) geladen. Dabei wird Ihre IP-Adresse an Apple übertragen. Ohne Klick passiert das nicht.

Lokaler Speicher: Der Befehlsverlauf des Terminals wird nur in Ihrem Browser gespeichert (localStorage) und nie übertragen. Sie können ihn jederzeit über die Browser-Einstellungen löschen.

Kontakt: Das Kontaktformular öffnet nur Ihr eigenes E-Mail-Programm; über diese Seite werden keine Daten verschickt.

Sie haben das Recht auf Auskunft, Berichtigung und Löschung Ihrer Daten sowie das Recht auf Beschwerde bei der österreichischen Datenschutzbehörde.
